# Neo4j Knowledge Graph

Cypher scripts sẽ được chuyển và chuẩn hóa ở giai đoạn Neo4j. Dự kiến gồm `schema.cypher`, `seed_diabetes.cypher`, `import_documents.cypher`, `queries.cypher`, `reset.cypher`.

Không tạo dữ liệu y khoa giả chỉ để làm graph demo. Mỗi fact cần provenance trỏ tới nguồn tài liệu và vị trí cụ thể.
